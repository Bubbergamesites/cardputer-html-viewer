# Contributing to CardPuter HTML Viewer

We welcome contributions! Please follow these guidelines:

## Development Setup

1. Fork the repository
2. Clone your fork
3. Create a new branch for your feature:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Code Standards

- Follow existing code style
- Use meaningful variable names
- Add comments for complex logic
- Test on actual CardPuter hardware when possible

## Commit Messages

- Use clear, descriptive messages
- Start with a verb: "Add", "Fix", "Update", etc.
- Example: "Add WiFi file download feature"

## Pull Request Process

1. Update documentation
2. Add tests if applicable
3. Create a pull request with description
4. Address review comments

## Reporting Issues

- Use GitHub Issues
- Include device model and firmware version
- Provide minimal reproducible example
- Attach relevant logs

## Feature Requests

Suggestions welcome! Please:
- Check existing issues first
- Describe the use case
- Explain expected behavior
